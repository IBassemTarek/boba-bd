# هدية عيد ميلاد بوبا

صفحة React عربية تفاعلية، جاهزة للنشر على Vercel.

## التشغيل

```bash
npm install
npm run dev
```

## صور بوبا والمحتوى

الصور الحالية موجودة بصيغة WebP داخل `public/photos`، والأغنية داخل `public/audio`.
يمكن تعديل الصور والنصوص والتوقيع من `src/content.js`.

الصفحة تتعامل مع الصورة المفقودة تلقائيًا وتعرض placeholder بدل أي رابط مكسور.

## الفحص والنشر

```bash
npm test
npm run build
```

ارفع المشروع إلى GitHub ثم استورده في Vercel؛ إعدادات Vite تُكتشف تلقائيًا ولا تحتاج متغيرات بيئة.
